# wpg-parcel-history

Per-neighbourhood historical snapshots of **City of Winnipeg** parcels —
assessment rolls and survey lots — behind the "as-of-date" compare view in
[winnipeg-opendata-parcelsearch](https://github.com/jayschellenberg/winnipeg-opendata-parcelsearch).
Served free via the [jsDelivr](https://www.jsdelivr.com/) CDN. Since
2026-09-14 the app draws the parcel and survey polygons from one whole-city
PMTiles archive per snapshot (built from these shards by the app repo's
`r/build_historical_tiles.R`, hosted on R2); the shards remain the source of
those archives. Since 2026-09-29 the whole-city as-of zoning (`zoning.json`)
is tiled into the same archive too, so it is build input only; the lineage
files are still fetched from here.

**All public open data** (City of Winnipeg Open Data). Generated by
`r/build_historical_shards.R` + `r/build_lineage.R` in the app repo from dated
source-of-record GeoPackages. No private or client data.

## Layout

```
index.json                       discovery: snapshots + per-layer source dates
<snapshot>/manifest.json         provenance (source_crs, sha256, dates, license)
<snapshot>/parcels/<SLUG>.json   assessment parcels  — keyed by official neighbourhood
<snapshot>/survey/<SLUG>.json    survey lots          — same neighbourhood slug universe
lineage/<SLUG>.json              assessment predecessor/successor  (by roll_number)
survey-lineage/<SLUG>.json       survey predecessor/successor      (by id)
```

`<snapshot>` is the source-file date `YYYY-MM-DD`. `<SLUG>` is an official
Winnipeg neighbourhood (e.g. `RIVER-HEIGHTS`).

Snapshots: assessment `2023-11-13` / `2025-02-26` / `2026-06-07`; survey
`2025-03-14` / `2026-06-07`.

## Not authoritative

Display geometry is **simplified** for visualization (lots < 1 ha kept exact; a
~0.3 m de-noise on all, ~2–3 m on larger parcels). **Lineage is inferred** from
geometry overlap of snapshots months apart. Both are **investigative aids** —
verify against the registered plan / title / by-law and the current
[winnipegassessment.com](http://www.winnipegassessment.com) record. Not a legal
survey or determination. Resolve area/boundary evidence back to the archived
source-of-record named in each manifest (`source_file` / `sha256`).
